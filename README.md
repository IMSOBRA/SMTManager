## 🚀 개요
`SMT Manager`는 특정 게임 프로세스를 감시하여 실시간으로 CPU Affinity(코어 할당)를 조정함으로써 SMT 기능을 소프트웨어적으로 비활성화해주는 도구입니다. 

v2.0에서 도입한 **WMI 이벤트 기반(Event-driven)** 즉시 감지를 유지하면서, v2.1에서는 설정 검증과 로그 안정성을 강화했습니다.

## ✨ v2.0~v2.1 주요 기능
- **WMI 이벤트 감시**: OS 레벨의 이벤트를 직접 수신하여 딜레이 없이 게임 프로세스를 감지합니다.
- **최소 점유율**: 게임 미실행 시 CPU 소모가 사실상 0%에 가깝게 최적화되었습니다.
- **백그라운드 최적화**: 트레이 아이콘으로 최소화 시 UI 오버헤드를 완전히 제거하며 백그라운드에서 완벽하게 동작합니다.
- **커스텀 마스크 지원**: 사용자의 CPU 환경에 맞춰 원하는 코어만 사용하도록 직접 Hex 마스크를 설정할 수 있습니다.
- **스마트 시작 등록**: 윈도우 부팅 시 자동으로 트레이에서 시작되도록 간편하게 등록 가능합니다.
- **프로세스 이름 정규화(v2.1)**: `heroes`와 `heroes.exe`를 동일하게 인식합니다.
- **설정 자동 보정(v2.1)**: 잘못된 설정값이 들어와도 안전한 기본값으로 복구합니다.
- **로그 회전(v2.1)**: 로그 파일이 커질 경우 자동 분할 보관합니다.

## 🛠️ 사용 방법
1. **실행**: `SMTManager_v2.1.exe`를 관리자 권한으로 실행합니다. (파이썬 사용 시 `SMTManager_v2_1.py` 실행)
2. **설정**: 게임 프로세스 이름을 확인하고, 필요시 '시작 프로그램 등록'을 누릅니다.
3. **최적화**: '백그라운드 실행'을 누르면 트레이로 숨겨지며 감시가 시작됩니다.
4. **종료**: 트레이 아이콘 우클릭 후 '완전 종료'를 선택합니다.
