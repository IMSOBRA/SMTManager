# SMT Manager 1.0.0

> by IMSOBRA
> 마비노기 / 마비노기 영웅전 실행 시 자동으로 SMT OFF용 CPU affinity를 적용하는 Windows 전용 프로그램

## 소개
`SMT Manager`는 지정한 게임 프로세스를 감지해서, 게임이 실행되는 동안 CPU affinity를 자동 조정하는 도구입니다.

이 프로그램은 BIOS에서 SMT를 직접 끄는 방식이 아니라, 게임 프로세스가 사용할 논리 코어를 제한해서 비슷한 효과를 내는 방식입니다.

## 1.0.0 릴리즈 핵심 내용
- 게임 실행 시 자동으로 SMT OFF용 affinity 적용
- 게임 종료 시 원래 CPU affinity 상태 복원
- WMI 이벤트 기반 즉시 감지
- 잘못된 마스크 값 자동 검증
- 트레이 상주 및 시작 프로그램 등록 지원
- 로그 파일 자동 회전

## 지원 기본 프로세스
- `client`
- `heroes`
- `heroes_x64`

## 사용 방법
1. `SMTManager_1.0.0.exe`를 관리자 권한으로 실행합니다.
2. 게임 프로세스 이름이 목록에 맞는지 확인합니다.
3. 필요하면 커스텀 마스크를 입력하고 저장합니다.
4. 창을 닫으면 트레이로 숨겨지고, 백그라운드에서 계속 감시합니다.
5. 완전 종료는 트레이 아이콘 메뉴에서 합니다.

## 커스텀 마스크
- 입력값은 16진수여야 합니다.
- 예: `55`, `AA`, `0x55`
- 비워두면 현재 CPU 기준으로 자동 계산합니다.

## 주의 사항
- 관리자 권한이 필요합니다.
- CPU affinity를 이용한 방식이라, 메인보드 BIOS에서 SMT를 끄는 것과 완전히 같지는 않습니다.
- 게임 외 프로그램에 별도 affinity 설정을 해둔 경우에도, 이 프로그램은 자신이 변경한 게임 프로세스만 복원하도록 설계되어 있습니다.
